# Repository Guidance
- Work only within the current directory; do not access parent directories or other locations.
- Only read and modify files inside the current working directory; never read from or write to any other directory.
- All file reads, edits, and commands must target paths within the current directory.
- Never read files or folders whose names start with `.`.
- If a requested permission is denied or rejected, continue the task and seek a non-permissioned alternative instead of stopping.
